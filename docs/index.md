# MacWiFi

MacWiFi is a native Swift CLI for macOS Wi-Fi diagnostics. It supports
`scan`, `info` and `password`, with tables or JSON. Detailed BSSID
scanning is opt-in with `--bssids`; default scans retain the SSID summary.

Start with [Getting started](getting-started.md) or read
[How it works](how-it-works.md). Build, signing and compatibility details
are in the [repository README](../README.md).
